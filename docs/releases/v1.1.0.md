## What's new

- **F95zone works again:** covers and screenshots download again after the site's update, and tags are now imported.
- **Erotorrent works again** after its move to erotorrent.org.
- **Seamless launcher updates:** a small notice in the title bar opens a window with what's new, the download progress
  and a restart. If a new version doesn't start, pLauncher goes back to the previous one by itself.
- **Errors in your language:** parser, backup and update errors are translated into all 11 languages.
- **A friendlier start:** an empty library shows a big **+** button to add your games folder.
- Updating metadata from a link no longer removes tags you added by hand.
- Dropdowns and scrollbars use the dark theme everywhere, including Linux.

## Updating from 1.0

Open **Settings → General → Launcher update** and click **Install**. Your library and settings stay as they are.
From this version on, updates show up in the title bar.

## Download

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `pLauncher.exe` — portable, just run it |
| Linux (x64) | `pLauncher-linux-amd64`, or `pLauncher-linux-amd64.tar.gz` |
| macOS (Intel + Apple Silicon) | `pLauncher-macos-universal.zip` |

Every file has a matching `.sha256` checksum.

## First launch

The builds aren't code-signed yet, so your OS will ask for confirmation once:

- **Windows:** SmartScreen shows *"Windows protected your PC"*. Click **More info → Run anyway**.
- **macOS:** macOS 15+ only offers *Move to Trash* / *Done*. Click **Done**, then open
  **System Settings → Privacy & Security** → **Open Anyway**, or run
  `xattr -dr com.apple.quarantine /Applications/pLauncher.app`. On macOS 14 and older, right-click → **Open** works.
- **Linux:** install WebKitGTK 4.1 (`sudo apt install libwebkit2gtk-4.1-0` on Ubuntu/Debian), then
  `chmod +x pLauncher-linux-amd64` if needed.

See also the [Code signing policy](https://github.com/BasteArima/pLauncher#code-signing-policy) and the
[Privacy policy](https://github.com/BasteArima/pLauncher#privacy-policy).

## Known limitations

- macOS builds don't update themselves: the launcher shows the new version with a link to its release page.
- The panic button (global hotkey) works only on Windows for now.
