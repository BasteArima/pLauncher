## What's new

- **A new look:** a flat dark theme, wide cards, line icons, search in the title bar and a new app icon.
- **Find game info by name:** pLauncher searches F95zone, Steam and VNDB by the folder name and shows the best
  matches. Preview one, then save it. No more hunting for the right page link.
- **Play sessions and statistics:** every session is recorded, even if you close the launcher while playing.
  The game page shows the last eight weeks; **Statistics** in the sidebar shows your week, month and year.
- **Several launch files per game:** the config tool and the walkthrough open from the menu beside Play, and only
  the game itself counts as playtime.
- **Your own tracker:** play status, a 5-star rating and private notes with `||spoilers||`.
- **Smart lists** for games without a cover, launch file or source link, each with one button that fixes the
  whole list (including a name lookup for every game without a link).
- Update notices show when the new version was found. Arrows on the game page move to the previous and next
  game of the list you came from. Mouse side buttons and Alt+←/→ go back and forward.
- Filter by several tags and exclude the ones you don't want. Covers can be framed separately for wide and tall
  cards.

## Updating from 1.1

Click the update notice in the title bar. Your library, playtime and settings stay as they are; the database is
copied to `backups/` before the update. Play sessions are recorded from this version on, so the weekly charts
start empty while your all-time playtime is kept.

From 1.0, open **Settings → General → Launcher update** and click **Install**.

| Windows 10/11 (x64) | `pLauncher.exe` — portable, just run it |
| Linux (x64) | `pLauncher-linux-amd64`, or `pLauncher-linux-amd64.tar.gz` |

Every file has a matching `.sha256` checksum.

## First launch

The builds aren't code-signed yet, so your OS will ask for confirmation once:

- **Windows:** SmartScreen shows *"Windows protected your PC"*. Click **More info → Run anyway**.
- **macOS:** macOS 15+ only offers *Move to Trash* / *Done*. Click **Done**, then open
  **System Settings → Privacy & Security** → **Open Anyway**, or run
  `xattr -dr com.apple.quarantine /Applications/pLauncher.app`. On macOS 14 and older, right-click → **Open** works.
- **Linux:** install WebKitGTK 4.1 (`sudo apt install libwebkit2gtk-4.1-0` on Ubuntu/Debian), then
  `chmod +x pLauncher-linux-amd64` if needed.

See also the [Code signing policy](https://github.com/BasteArima/pLauncher#code-signing-policy) and the
[Privacy policy](https://github.com/BasteArima/pLauncher#privacy-policy).

## Known limitations

- macOS builds don't update themselves: the launcher shows the new version with a link to its release page.
- The panic button (global hotkey) works only on Windows for now.
- Playtime is recorded for games started directly (`.exe` and native launchers). Files opened through the system
  (HTML games, `.swf`, documents) are launched but not timed.
