The first public release of **pLauncher**: a private, Steam-like launcher for your local game library.
Point it at your games folder and it finds every game, fills in covers and descriptions, tracks playtime and
tells you when a new version is out. Everything stays on your machine.

## Highlights

- **Folder scanning** with automatic launch-file detection (`.exe`, HTML, `.bat`, `.jar`, `.swf`, QSP, RAGS, LÖVE;
  `.sh`, `.x86_64`, AppImage and `.app` on Linux/macOS) and engine detection (Ren'Py, Unity, RPG Maker and 10 more).
- **Metadata from a link:** paste a page from F95zone, Pornolab, Erotorrent, Island of Pleasure or Steam to get the
  title, version, author, tags, description, cover and screenshots.
- **Update tracking** per source: *Check all* marks the games with a newer build.
- **Steam-style library:** hero banner, rearrangeable shelves, collections (manual or by tags), favorites, search,
  sorting, adjustable card size, playtime and folder size.
- **Privacy:** cover blur (until hover / always, `Ctrl+H`), PIN lock with auto-lock, a global panic button (Windows)
  and hidden collections.
- **Big-library tools:** bulk actions, keyboard navigation (`F1` for the list), relinking moved games, ignored
  folders, backup and restore to a single `.zip`.
- **Self-update** on Windows and Linux with SHA-256 verification.
- **11 languages:** English, Deutsch, Español, Français, Polski, Português (Brasil), Türkçe, Русский, Українська,
  日本語, 简体中文. You can add your own.

## Download

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `pLauncher.exe` — portable, just run it |
| Linux (x64) | `pLauncher-linux-amd64`, or `pLauncher-linux-amd64.tar.gz` |
| macOS (Intel + Apple Silicon) | `pLauncher-macos-universal.zip` |

Every file has a matching `.sha256` checksum.

## First launch

The builds aren't code-signed yet, so your OS will ask for confirmation once:

- **Windows:** SmartScreen shows *"Windows protected your PC"*. Click **More info → Run anyway**.
- **macOS:** macOS 15+ only offers *Move to Trash* / *Done*. Click **Done**, then open
  **System Settings → Privacy & Security** → **Open Anyway**, or run
  `xattr -dr com.apple.quarantine /Applications/pLauncher.app`. On macOS 14 and older, right-click → **Open** works.
- **Linux:** install WebKitGTK 4.1 (`sudo apt install libwebkit2gtk-4.1-0` on Ubuntu/Debian), then
  `chmod +x pLauncher-linux-amd64` if needed.

Then pick a folder for pLauncher's data and add the folders with your games.

## Known limitations

- The panic button (global hotkey) works only on Windows for now.
- macOS builds don't update themselves: the launcher shows the new version with a link to its release page.
- Parsers depend on each site's page layout. If one stops working, please
  [open an issue](https://github.com/BasteArima/pLauncher/issues) with the link.
