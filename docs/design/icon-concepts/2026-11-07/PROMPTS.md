# pLauncher icon concepts

Created 2026-11-07 using the built-in image generation tool.

Four exploratory alternatives for the flat redesign. The application icon and UI have not been replaced.

- `01-flat-p.png`: familiar lowercase p, simplified for the flat theme.
- `02-p-play.png`: lowercase p with a negative-space play triangle.
- `03-library-play.png`: a stack of game cards with a play triangle.
- `04-launch-mark.png`: an open gateway with a play triangle.

Palette direction: graphite #0E1014 / #161920, muted violet #6D5BD0, accent #8C7CF0, off-white #F4F5F8. These are raster concepts, not pixel-perfect production vectors. The generator retained subtle tonal variation despite the flat-fill brief.

Validation: visually reviewed all four images; dimensions and transparent corner alpha checked. No application integration, executable build, or real taskbar-size visual acceptance performed.

### 01-flat-p

```text
Use case: logo-brand.
Asset type: desktop application icon concept for pLauncher, a private local game library and game launcher.
Design context: newly redesigned app has a sophisticated flat dark interface, cool graphite #0E1014 and #161920 surfaces, muted violet #6D5BD0 primary accent, lighter violet #8C7CF0, off-white #F4F5F8. Typography in app is Inter. Icon should fit this flat restrained design and be discreet, neutral, elegant, not adult-themed.
Output one standalone square icon, approximately 1024x1024. Large perfectly front-facing rounded-square dark graphite tile occupying 90% of the image, with genuine transparent outside corners. Center a single bold distinctive symbol with generous internal padding. Sharp vector-like geometric edges, precise visual balance, clean flat fills. Must remain readable at 24px and 32px. No presentation board, no duplicate size previews, no captions, no words, no watermarks. Avoid gradients, glow, textures, glass, neon, bevels, 3D, cast shadows, thin fragile lines, rockets, controllers, padlocks.
Concept A — refined lowercase p monogram, preserving recognition of the old pLauncher icon. Main symbol is one bold custom lowercase Latin p in light lavender #B7ADFF: short rounded vertical stem, large geometric round bowl, generous dark counter. Upright and confident, restrained engineered curves. The p is slightly above visual center to balance its descender. No play triangle, no extra decoration. The letter itself is the entire brand mark.
```
